# 🎨 Doodle Recognition using Deep Learning

A real-time doodle recognition system developed as part of my Machine Learning Internship. This project uses Convolutional Neural Networks (CNNs) to classify hand-drawn sketches into predefined categories, demonstrating the application of deep learning techniques for image classification.

---

## 🚀 Overview

Hand-drawn sketches are highly unstructured and vary significantly between users. This project builds a CNN-based image classification model capable of recognizing doodles in real time by learning visual features directly from sketch images.

The project covers the complete machine learning workflow including data preprocessing, model development, training, evaluation, and prediction.

---

## ✨ Features

- Real-time doodle classification
- CNN-based image recognition
- Image preprocessing and normalization
- Multi-class classification
- Model training and evaluation
- Interactive prediction workflow
- Performance visualization using training metrics

---

## 🧠 Model Architecture

The model is implemented using TensorFlow/Keras Sequential API and consists of:

- Convolutional Layers
- ReLU Activation
- Max Pooling Layers
- Feature Flattening
- Fully Connected Dense Layers
- Softmax Output Layer

The architecture is designed to automatically learn hierarchical image features for accurate doodle recognition.
